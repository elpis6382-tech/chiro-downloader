# 영상 다운로더

링크만 넣으면 영상을 **진짜 MP4**로 받아서 폰의 `Download/Chiro video` 폴더에 저장하는 안드로이드 앱.

- 유튜브·인스타·틱톡·X·비메오 등 [yt-dlp가 지원하는 사이트](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md) 전부, 그리고 영상이 들어 있는 일반 웹페이지
- 아래 탭 4개: **홈**(브라우저) · **받는 중** · **파일** · **설정**
- **홈**: 검색창, 사이트 바로가기(길게 눌러 빼기, + 로 추가), 최근 받은 영상, 복사해 둔 링크가 있으면 [받기]
- **브라우저**: 탭 여러 개, 광고·팝업 차단, 웹 영상 전체화면. 영상이 있는 페이지에서는 오른쪽 아래 **파란 다운로드 버튼**이 켜지고(찾은 개수 표시), 누르면 제목·썸네일·화질별 예상 용량을 보고 받기. yt-dlp가 못 읽는 페이지는 페이지가 재생한 영상을 골라 받기. 사이트의 다운로드 버튼도 그대로 동작
- 다른 앱에서 **공유 → 영상 다운로더** 를 누르면 앱이 열리지 않고 바로 받기 시작
- **받는 중**: 진행률·속도·남은 시간, **일시정지/이어받기**(받던 조각을 남겨 두고 이어서), 실패하면 [다시]
- **파일**: 썸네일·길이, 영상/음악별 보기, 검색, 공유·다른 앱으로 열기·이름 바꾸기·삭제
- **내장 플레이어**: 이전/다음, 배속, 화면 돌리기, 두 번 탭해서 10초 이동, 왼쪽 밀기 밝기·오른쪽 밀기 소리
- 같은 영상은 두 번 받지 않음 (받은 영상이 폰에 있거나 받는 중이면 대신 그걸 보여줌, 지운 뒤에는 다시 받을 수 있음)
- 영상 정보 확인을 빠르게: yt-dlp를 미리 켜 두고 재사용, 제목·썸네일은 바로, 복사한 링크는 미리 확인, 다운로드는 확인 결과로 바로 시작
- 앱 안에서 **새 버전 업데이트** (버튼 한 번으로 받고 설치)
- 화질 고르기: 최고 화질 / 1080p / 720p / 480p / 소리만(M4A)
- **빠르게**: 파일 하나를 16개 연결로 나눠 동시에 받기(aria2c, 1MB 단위로 나눠서 작은 영상도), 스트리밍 조각 8개씩 동시에, 동시에 받을 개수 1~5개(설정). 사이트가 나눠 받기를 막으면 자동으로 일반 방식으로 다시 받기
- 브라우저에서 로그인해 두면 로그인이 필요한 영상도 받기 (유튜브는 로그인 없이 먼저 시도)
- 화면을 꺼도 계속 받고, 알림에 진행률·일시정지·취소 버튼
- 다운로드 엔진(yt-dlp)을 하루 한 번 자동으로 최신으로 업데이트, 실패하면 새 엔진으로 한 번 더 시도
- 유튜브 처리에 필요한 JavaScript 엔진(QuickJS-NG)을 앱에 같이 넣음

DRM으로 보호된 영상(넷플릭스 등)은 받을 수 없어요. 저작권이 있는 영상은 개인적으로 볼 용도로만 쓰세요.

## 설치

[최신 릴리스](../../releases/latest)에서 `video-downloader.apk`를 받아 설치. 새 버전은 그대로 덮어 설치하면 돼요.

## 만드는 방법

`main`에 올리면 GitHub Actions가

1. QuickJS-NG를 안드로이드용으로 컴파일하고
2. 앱을 빌드한 뒤
3. (손으로 실행할 때만: Actions → build → Run workflow) 안드로이드 13 에뮬레이터에서 실제 엔진으로 다운로드 테스트(HLS 스트림이 있는 웹페이지 → MP4, 소리만 → M4A, aria2c 16연결, 엔진 업데이트, JS 엔진 인식)와 앱 화면 테스트(공유, 브라우저의 다운로드 버튼과 화질 시트, 페이지가 재생한 스트림, 사이트 다운로드 버튼, 탭, 느린 다운로드 일시정지 → 이어받기 후 원본과 똑같은지, 파일 목록, 플레이어, 설정)를 하고
4. 통과하면 APK를 `latest` 릴리스에 올려요. 릴리스는 지우지 않고 파일만 바꿔서 링크가 끊기지 않아요.

엔진: [youtubedl-android](https://github.com/JunkFood02/youtubedl-android) (Python + yt-dlp + ffmpeg)
